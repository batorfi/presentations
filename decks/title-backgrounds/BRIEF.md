# Deck brief — Title-slide backgrounds

* **Working title:** Title-slide backgrounds (framework demo)
* **Audience:** deck authors using the presentations framework
* **Goal:** show the five "edge-…" themes that animate only in the right quarter of a title slide, and how to use them
* **Slides:** one per theme (network, branches, pcb, hex, stars), an options slide, a how-to slide
* **Hard constraints:** text stays in the left three quarters; no content claims beyond what the framework does
